# 用户管理

用户管理功能可由管理员（拥有 `isAdmin` 标识的用户）在侧边栏的[邀请](#邀请)和[用户](#用户)页面中访问。

> [!IMPORTANT]
> 终端用户通过[邀请](#邀请)或开放注册创建，始终可以选择自己的密码；管理员可以通过邀请预设其用户名和初始配置。管理员账户也可以通过 CLI `goauth create-admin` 创建。

## 邀请

邀请创建/更新页面。

<p align=center>
<img width="500" alt="邀请页面" src="/public/screenshots/invitation.png" />
</p>

创建邀请时，可以设置未来用户的用户名和初始配置信息。未填写的字段可以由用户在接受邀请时填写，但用户名或邮箱必须至少填写一项。用户的初始安全组也可以在此选择。

邀请创建后，邀请链接将在页面顶部生成并显示。Goauth 不包含邮件功能，链接需要复制后由管理员手动发送给用户。

> [!IMPORTANT]
> 被邀请的用户始终处于"已批准"状态。如果管理员设置了初始邮箱地址，该邮箱在接受邀请时将被自动验证。

## 注册

如果 **APP_UI_SIGNUPENABLED** 环境变量设置为 `true`，用户可以自行注册。首个注册的用户将自动成为管理员并直接通过审批；后续注册的用户需要管理员审批后才能登录。

## 用户

用户更新页面。

<p align=center>
<img width="500" alt="用户编辑页面" src="/public/screenshots/user-edit.png" />
</p>

在用户更新页面，可以修改用户的所有配置信息和用户名。用户的安全组、邮箱验证状态和审批状态也可以在此设置。
