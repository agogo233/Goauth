# Goauth 修复计划

33 项问题经代码复核确认。全部 5 批 33 项已全部完成修复（2026-11-14）：第 3 批 #13-#18、第 4 批 #19-#21、第 5 批 #22 已实现并通过 `go build` + `go test ./...` 全量验证。

> **状态更新**：
> - 第 1 批 #1-#6 已全部在代码中实现（PKCE、PostLogoutRedirectURIs、密码重置审计日志、RequiresApproval 字段）。
> - 第 2 批 #7-#12 已修复。其中 #9 经评审调整：OIDC 端点不适用 cookie-CSRF（authorize/endsession 为跨站导航请求，token/introspect/revoke 为服务器间调用），改为在 `main.go` OIDC 路由组处注释说明防护机制（state / PKCE / client 认证 / post_logout 校验）。
> - 相关安全基线变化：bcrypt 默认 cost 提升至 12（`APP_SECURITY_BCRYPTCOST` 可配）；登出接口已纳入 CSRF 保护；CORS 通配符放行不再携带凭据；CSRF token 在密码修改 / MFA 绑定 / 备用码验证成功后轮换。
